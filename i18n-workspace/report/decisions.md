# 决策记录

格式：问题 / 可选方案 / 选择 / 影响 / 日期

## D-001 英文语言包的处理方式

- **问题**：key 即英文原文时，`en.json` 是否有必要逐条维护。
- **可选方案**：A. en.json 列出全部 key→英文；B. en.json 保持空对象，依赖 i18next 回退返回 key 本身。
- **选择**：B。
- **影响**：英文界面永远等价于源码原文，不存在"语言包漏项导致英文缺字"的风险；代价是英文侧无法单独润色文案。
- **日期**：2026-10-23

## D-002 key 分隔符关闭

- **问题**：原文 key 含 `.`、`:`（如 `Status: Loading...`），默认会被当作命名空间/嵌套分隔符。
- **选择**：`keySeparator: false`、`nsSeparator: false`，全站单一 `translation` 命名空间。
- **影响**：key 中可自由出现标点；后续若要拆命名空间需重新设计 key 规范。
- **日期**：2026-10-23

## D-003 图标文本不参与翻译

- **问题**：`i18next-cli lint` 把 `<span class="material-symbols-outlined">expand_more</span>` 的
  图标名也算硬编码（`expand_more` 29 次、`account_tree` 13 次等）。
- **可选方案**：A. 一并包 `t()`；B. codemod 跳过 `material-symbols` 子树；C. 人工清理。
- **选择**：B。codemod 通过 AST 判断文本节点的父元素 class 是否包含 `material-symbols`，命中即跳过并计入 skipped。
- **影响**：`frequency.csv` 中的图标名不计入翻译范围，覆盖率统计需扣除；语言包保持干净。
- **日期**：2026-10-23

## D-004 验证环境

- **问题**：源项目占用 1425（`strictPort: true`），app 无法同端口启动。
- **选择**：app 开发服务器固定用 `npm run dev -- --port 1426`，该改动不提交；后端复用源项目 8780。
- **影响**：Playwright 验收脚本默认指向 `http://localhost:1426`，可传参覆盖。
- **日期**：2026-10-23

## D-005 语言下拉文案

- **问题**：语言选项在切换前后需要保持可识别。
- **选择**：下拉选项分别以各自语言显示（`English` / `简体中文`），区块标题走 `t('Language')`。
- **影响**：切回英文时，"简体中文"选项本身保留中文，符合 PLAN §12 第 7 条的例外。
- **日期**：2026-10-23

## D-006 伪本地化的实现方式

- **问题**：PLAN §5.1 设想新增 `pseudo` 语言并切换过去，但该语言需注册进 `src/i18n`，会污染交付物。
- **选择**：改用「临时替换 zh-CN 译文 → 跑 Playwright → finally 还原」的方案，效果等价（同样能暴露漏网英文与溢出）。
- **影响**：不新增语言资源；`tools/pseudo-localize.mjs` 用 `copyFileSync` 备份与还原，异常路径也在 finally 中恢复。
- **日期**：2026-10-23

## D-007 教学长文最终已全部翻译（原"不翻"记录作废）

- **问题**：`LearnLangChainTab`（911 行）、`BestPracticesTab`（894 行）、
  `EmptyStateContent`、`LibraryContentPanel` 是长篇教学资料。
  早期按 PLAN「用户要读的资料不翻」的原则，曾决定不翻译。
- **最终选择**：按用户明确要求改为**全量翻译**。四个文件共 **366 个 `t()` key，缺译文 0 条**。
- **影响**：语言包新增约 291 条长句译文；组件结构未变，只做 `t()` 包裹；
  24 个长段落按句拆分，11 个含 `&` 的标题手工包裹（codemod 的 HTML 实体规则会跳过）。
- **仍不翻译的内容**：代码块、示例命令、`material-symbols` 图标名、模型标识。
- **备注**：2026-10-23 核查发现本条早期记录（标题为「教学长文不翻」）与事实不符，已更正。
- **日期**：2026-10-23（同日修订）

## D-008 技术常量跳过规则

- **问题**：`<code>` 内的 `ollama pull llama3.2`、`http://localhost:11434`、`text-embedding-3-small (OpenAI)` 被 codemod 包进 `t()`，翻译会破坏命令。
- **选择**：新增两层跳过——`insideLiteral()`（`code`/`pre`/`kbd` 子树）与 `looksTechnical()`（URL、域名、`model:tag`、命令前缀、路径、模型名）。
- **影响**：这些字符串保持英文且不进入语言包；已写入 `coverage.md` 白名单。
- **日期**：2026-10-23

## D-009 验收脚本依赖后端限流

- **问题**：连续跑 Playwright 验收会触发后端 60 req/min 限流，导致设置页停在加载态。
- **选择**：脚本改为等待 `select` 出现 + 失败重载一次；本地复跑前建议间隔 1 分钟。
- **影响**：验收结果更稳定；CI 化时需提高后端限流阈值或加缓存。
- **日期**：2026-10-23
